Vehicle registration data from VAHAN drives market-share tracking, fuel-preference trends, and sales planning — but pulling it by hand means visiting every State and Union Territory separately, one report at a time. This automation does that visiting for you, on a schedule, and hands back a single checked, ready-to-use file instead of dozens of loose downloads.

Below are the two report types running today. Each follows the same shape: connect, collect, check, deliver.

State-wise Monthly Report

Workflow 1 · Vahan_StateMonthwise

Registration counts by vehicle maker, broken down by month, for every State and Union Territory — the base figure everything else gets checked against.

1

Open the VAHAN portal

Connects to the official reporting page and confirms it has loaded correctly before doing anything else.

2

Apply the standard filters

Sets vehicle category and the current reporting year the same way, every time — no filter is ever left on a stale value from a previous report.

3

Step through all 36 States & UTs

Works through the full list one at a time, in order, so none are skipped.

4

Clear the security check

Reads and solves the portal's captcha automatically at each state, without a person clicking through it.

5

Download & combine

Pulls that state's report, then packages all 36 into a single organised file.

6

Check the totals

Adds up the Mercedes-Benz and BMW figures across all 36 states and compares that sum against an independent all-India total, to confirm nothing was missed or counted twice.

7

Email the result

Sends the packaged report and a pass/fail summary straight to the inbox — no one has to remember to go check.

State-wise Fuel Report

Workflow 2 · Vahan_StateFuelwise

The same state-by-state pull, but broken down by fuel type and repeated for every month of the year so far — showing how fuel preference is shifting, month over month, across regions.

1

Open the VAHAN portal

Same starting point as the monthly report, confirmed loaded before proceeding.

2

Apply the standard filters

Same consistent filter setup, this time reading the fuel-type breakdown instead of the plain monthly total.

3

Step through every state, every month

For each of the 36 States & UTs, it repeats the pull for January through to the current month — so a state isn't just one report, it's one per month.

4

Clear the security check

Solves the captcha automatically at every state-month combination along the way.

5

Download & combine

Pulls each state-month's report and packages the full set into one organised file.

6

Check against Workflow 1

Adds up this year's Mercedes-Benz and BMW figures month by month, per state, and checks that total against Workflow 1's own numbers for the same state — a second, independent cross-check.

7

Email the result

Sends the packaged report and a pass/fail summary straight to the inbox as soon as the batch finishes.

Built In

What both workflows share

A handful of things run quietly underneath every batch, on every workflow.

Automatic security check

The portal's captcha is read and solved on its own at every step — no manual clicking required to keep a batch moving.

Built-in accuracy check

Totals are cross-checked before a batch is called complete, and anything that doesn't add up is flagged rather than quietly delivered.

Automatic email summary

A results email goes out the moment a batch finishes — no one has to remember to check in.

Consistent file naming

Every report follows the same naming pattern, so files never get mixed up or misfiled.

Keeps going when something breaks

A dropped connection or a failed step doesn't lose the whole batch — it recovers and carries on.

Full run history

Every batch is logged with a timestamp and a result, so any report can be traced back to exactly when and how it was produced.
